# People

Read the recipient's profile before writing to them. The chat provider (`$kit.chat -To <alias>`) reads the emails from this table.

This is the kit's empty file. A project pack ships its team's file (`people.md` in the pack), which replaces this one. Your own additions and corrections go in your file (`paths.myPeople` in the configuration), with the same table and profile shape; a row there wins over the same alias in the team's file, and your file never needs merging when the kit is updated.

## Profiles

One section per person, titled `## <Name> (`alias`)`: who they are, the language to write in, and how they like to be asked.
