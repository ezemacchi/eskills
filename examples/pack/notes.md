# Project notes: Example (EXA)

What the skills need to know about this project and do not keep in code.

## Project

- Project `EXA`, board `12`, two-week sprints named `EXA Sprint <n>`.
- Stories move To Do, In Progress, In Review, Done. A story in review is ready to test once its change is on the test environment.

## Tests

- Test cases are issues of type `Test`, linked to their story with "is tested by".
- A failed test is reported as a `Bug` linked to the story with "relates to".
