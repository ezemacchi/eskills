# People

Read the recipient's profile before writing to them. The chat provider reads the e-mails from this table.

This is the example project's team file. Your own additions go in your file (`paths.myPeople`), which wins for the same alias.

| Alias | Email | Language | Asked about |
|---|---|---|---|
| `dana` | dana.dev@acme.invalid | English | the code: how a change was made, why a test fails |
| `pat` | pat.product@acme.invalid | English | product questions: what the user sees and does |
| `quinn` | quinn.qa@acme.invalid | Spanish | test data, test environments |

## Dana Dev (`dana`)

- Developer. Questions may name the code and the trade-off.
- English. Short: one line of context, then the question.

## Pat Product (`pat`)

- Product owner. Write in terms of what the user sees, not the code.

## Quinn QA (`quinn`)

- Runs the test environments. Spanish.
